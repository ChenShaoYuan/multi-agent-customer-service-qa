# 评级与业务反馈生成

| 情况 | 评级 | 是否输出业务总分 |
| --- | --- | --- |
| 总分≥90 | 优秀 | 是 |
| 60≤总分<90 | 合格 | 是 |
| 总分<60 | 严重问题 | 是 |
| 红线命中 | 严重不合格 | 否，三维短路 |
| 输入、时效资料或关键结果不完整 | 待人工复核 | 否 |

阈值读取scoring.yaml；0、59.99、60、89.99、90、100均有边界测试。非法负分、超100、NaN、无限值拒绝。

反馈由确定性模板生成：summary.yaml为13个子项提供具体改进方向，也给出优秀、合格、严重问题的整体建议。每条扣分建议保留issue_id、item_ids、rule_ids和evidence_message_ids，方便定位原文。

去重恢复项不再重复生成扣分建议；原始findings和duplicate_resolutions保留所有处理证据。红线建议要求优先核查与纠正，不用0分冒充模型计算完成。

JSON是完整数据契约，Markdown展示总分、原始三维表、调整后的加权贡献、改进建议、告警和工具调用记录。Markdown中的原文仅用于本地审阅，不应被当成已全面脱敏的数据。
